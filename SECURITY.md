# Security

MComix opens files from anywhere: archives, PDFs, pictures.
A file that crashes it, runs code, or writes outside its folders is a security issue.

## Report

Report privately: [open a security advisory](https://github.com/twwn/mcomix/security/advisories/new).
Please don't open a public issue.

You get a first answer within a week at most.

## Disclosure

A confirmed vulnerability is fixed in a release.
The advisory is published once that release is out, naming the reporter if they wish.

## Supported versions

The latest release only.
